吃好饭 · 隐私政策

更新日期：2026-07-19  |  English

我们深知隐私的重要。吃好饭的设计原则是：你的数据只属于你。

1. 本地工具，无自有服务器

  • 本应用是本地工具客户端，不搭建任何自有后端服务器；我们不会收集、上传或存储你的任何数据——包括食材、菜单、打卡、记账、成员档案、与 AI 的对话/配餐请求内容，以及你填写的第三方 API 密钥。
  • 全部数据仅保存在你的手机本地。删除方式：设置 → 危险操作 → 删除所有数据，即可随时全部清空；AI 服务的 API Key 可在「设置 → AI 配菜服务」中随时清除或更换。

2. 第三方 AI 服务（可选，仅在你主动授权并发起时）

  • 你自行配置第三方 AI 服务商（如 DeepSeek、豆包、OpenAI 等）的 API Key 后，配菜/拍照识别/健康周报请求会把相关文本或图片由本机直接发送至你所选服务商的服务器；数据传输与处理由该服务商负责，受其隐私政策约束。
  • API Key 仅保存在你本机本地，不会上传至任何服务器。不配置 AI 则完全离线可用。
  • iCloud 备份（仅 iOS，可选）：备份文件存于你自己的 Apple 账户。

3. 系统权限用途（均按需申请，可拒绝；除此之外不申请任何权限）

  • 本应用不读取通讯录、定位、短信等与功能无关的权限；网络调用仅在你主动发起请求（AI 配菜、拍照识别等）时发生。
  • 通知：饭点陪伴提醒（一天最多两条，可关闭）。
  • 麦克风与语音识别：与青团团语音聊天时即时转文字，不存储录音。
  • 相机/相册：仅在你主动使用「拍小票识别」时申请，图片仅发往你配置的 AI 服务商，本应用不留存。
  • 剪贴板：仅在你主动点击「复制」类按钮时写入。

4. 未成年人

本应用不面向 14 周岁以下儿童单独提供服务，建议在监护人指导下使用。
