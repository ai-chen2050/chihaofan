## 1.0.0 · 2026-08-01

首个 App Store 版本。iPhone / iPad。

**核心功能**

- 可视化虚拟冰箱：四分区收纳、拖拽整理、红黄绿保质期预警、待采购区、一键清理
- 今晚吃什么：AI 按「库存优先 → 预算约束 → 忌口规避」生成单日 / 3 日 / 周食谱，单道菜可随手替换
- 缺口买菜清单：排好餐自动汇总缺什么，实时预算联动，超支给平价替代
- 记账与复盘：四分类自动记账、日 / 周 / 月报表、营养分析
- 青团团养成：打卡喂「团气」，进化形态全部免费
- 档案中心：多人健康档案，各自独立的忌口与健康目标

**进阶版（¥18 一次性解锁，无订阅）**

- 多天采购计划、拍照 / 小票识别入库、AI 健康周报
- 数据导出导入与 iCloud 备份、界面主题 B/C、动态 App 图标

**关于数据**

- 全部存在本机，无账号、无服务器、无广告、不收集任何数据
- AI 使用你自己的 API Key，请求从手机直连服务商
- ⚠️ 本地存储意味着**换机或卸载前请先备份**（设置里开 iCloud 备份，或导出同步码）
