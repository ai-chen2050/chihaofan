FAQ

常见问题解答

关于配餐逻辑、数据存储、跨端支持与订阅模式的详细说明

吃好饭是如何在 3 秒内完成智能配餐的？

吃好饭借助大语言模型推理引擎，遵循白盒三重约束算法：1. 冰箱库存临期优先（优先消耗即将过期的食材，杜绝浪费）；2. 预算与成本控制；3. 饮食忌口与家庭成员偏好规避。3秒内给出主菜、副菜与热汤组合，所缺少的辅料自动汇入买菜清单。

为什么说吃好饭能做到极致的数据隐私保护？

吃好饭坚持纯正的「零服务器架构（Zero-Server Architecture）」。我们不搭建任何存储用户私密数据的中心化后台，食材、开支账目、家庭饮食档案全部存储在用户的手机本地沙盒中。即使多设备同步，也仅通过用户自己的 Apple 私人 iCloud 完成。

华为应用市场版与 iOS 版有什么区别？

华为应用市场版目前暂不含 AI 相关功能（AI 智能配餐、青团团聊天、小票拍照识别、AI 健康周报），原因是国内上架生成式 AI 功能需算法备案与安全评估资质，正在办理中。除 AI 相关功能外，3D 冰箱管理、食谱库、买菜清单、记账与青团团养成等功能与 iOS 版完全一致。

如何使用自己的 API Key (BYOK)？

吃好饭支持“自带 Key（Bring Your Own Key）”模式。在 App 设置中可以填入你自己的 OpenAI / DeepSeek / 通义千问等兼容 API 接口地址与密钥，所有请求直接由你的手机直连 AI 服务商，中间无任何中转代理。

换机或卸载 App 后，我的数据会丢失吗？

由于我们不在云端存你的数据，请在更换手机或抹掉设备前，在设置中开启“iCloud 云备份”，或在档案中心导出一份离线 JSON 备份文件。换新机后一键即可原样恢复全部食材与历史记录。

你的每一口饭菜数据，都只属于你自己

吃好饭是一款真正的本地离线优先工具，开发者零自有服务器。食材清单、记账金额、家庭体质档案均存放在你的设备本地沙盒中，守护最纯粹的生活烟火气。
